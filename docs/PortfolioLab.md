# Portfolio Lab

Updated: October 27, 2026. Status: **shipped in Tools; educational what-if, not advice**.

Portfolio Lab answers one question for cross-border investors: *how does the cost
of converting money change which mix of funds makes sense, and what would that
have meant over time?* A Canadian student who converts at a bank pays about 2.5%
before owning anything. Portfolio Lab treats that conversion as a trading cost
inside a mean-variance optimizer, so an expensive conversion visibly keeps more
money in home-currency funds, and compares bank conversion, brokerage
auto-conversion and Norbert's Gambit side by side.

## How the pieces fit

```
Bank of Canada Valet API ─▶ PySpark pipeline ─▶ fx-snapshot.json ─┐   (public data, cloud)
  (open data)               validate, month-end,  bundled in app  │
                            Parquet history                       ▼
Tiingo (person's own token) ─────────────────────────▶ Swift engine on device ─▶ SwiftUI
  (licensed data, device only)                          checks · returns · risk
                                                        model · optimizer · backtest
Python research reference ─▶ parity fixtures ─▶ Swift tests (macOS and Linux)
```

| Stage | Where | What it does |
| --- | --- | --- |
| Ingest and validate | `services/portfolio-lab/pipeline/fx_pipeline.py` | PySpark job: types and deduplicates daily USD/CAD, records rejected rows with reasons, keeps the last business day of each complete month, writes Parquet (local, `s3a://` or Unity Catalog volume) and the app snapshot |
| Research reference | `services/portfolio-lab/portfolio_lab/model.py` | NumPy risk model, SciPy SLSQP optimizer (buy/sell split for costs), backtest |
| Production engine | `NomadFi/NomadFi/Core/PortfolioLab/Engine` | The same model in Swift: vendor checks, home-currency returns, shrunk covariance, exact FISTA optimizer with a bisection proximal step, cost-aware backtest. Compiled into the app and the root Swift package |
| Parity | `services/portfolio-lab/fixtures/parity.json` | Generated by the Python reference; the Swift tests must match weights to 2e-6 and every backtest figure to 1e-5 relative |
| App | `Features/PortfolioLab` | Inputs, optimized mix, conversion comparison, chart with a month-by-month table, data checks, credits |

The split is deliberate: only openly licensed data passes through the cloud,
and the person's prices and amounts never leave the iPhone.

## The model

- **Returns** are converted into the investing currency with month-end Bank of
  Canada rates and kept only for months where every fund and the rate exist in
  both that month and the one before. At least 24 months are required.
- **Risk:** sample covariance, annualized, with off-diagonal terms shrunk 50%
  toward zero.
- **Expected returns:** either each fund's history pulled halfway toward the
  cross-sectional average, or the same for every fund (a risk-and-cost-only
  view). Neither is a forecast.
- **Optimizer:** maximize `μ·w − λ·wᵀΣw − Σ cᵢ|wᵢ − w0ᵢ|` with `Σw = 1`,
  `0 ≤ w ≤ 60%`. `cᵢ` is the conversion cost for foreign funds plus any
  commission. λ is 8 (cautious), 3 (balanced) or 1.2 (growth). Cash at 2% is
  optional.
- **Backtest:** invest once, drift with returns, rebalance yearly, and pay
  conversion costs on every trade, which is conservative for sales.

Conversion costs are typical published retail rates, not quotes: bank 2.5%,
brokerage auto-conversion 1.5%, Norbert's Gambit 0.1% plus about $20 in two
commissions. The pipeline publishes them in the snapshot so they change in one place.

| Tiingo end-of-day prices | Fetched on device only | Developer program: apps may integrate Tiingo when each user supplies their own token; "Data sourced by Tiingo" is shown with a link. Serving prices from NomadFi's servers would need a redistribution license ([developer program](https://www.tiingo.com/documentation/appendix/developers)) |
| Sample prices | Bundled | Generated by `portfolio_lab/sample.py`; always labeled illustrative |

Tiingo's coverage is US-listed securities, so live mode compares VTI, VXUS and
BND with home-currency cash. Canadian-listed funds appear in sample mode.
The Bank of Canada does not publish a TTD rate; a Trinidad and Tobago home
invests from the person's CAD or USD jurisdiction instead.

## Running it

```sh
cd services/portfolio-lab
uv sync --extra pipeline                   # Java 11 or 17 for PySpark
uv run pytest -q                           # model and Spark transforms
uv run python -m pipeline.fx_pipeline \
  --parquet /tmp/fx --snapshot ../../NomadFi/NomadFi/Resources/PortfolioLab/fx-snapshot.json
uv run python -m portfolio_lab.parity      # sample data and parity fixtures
cd ../.. && swift test --filter PortfolioLab --scratch-path /tmp/nomadfi-spm
```

`.github/workflows/portfolio-lab.yml` runs the research tests, a parity
freshness check and the Swift tests on Linux. `portfolio-lab-refresh.yml`
reruns the pipeline on the 3rd of each month and commits only when a new
month-end rate exists.

**Databricks:** `services/portfolio-lab/databricks.yml` deploys the same
pipeline as a serverless job (`databricks bundle deploy && databricks bundle run
portfolio_lab_fx`). Free Edition is for non-commercial use and limits outbound
internet, so the job reads a saved Valet response from a Unity Catalog volume.
**AWS:** pass an `s3a://` path to `--parquet` on EMR or any Spark cluster with
S3 credentials.

## Limits

- Educational only. No fund is recommended, and the result says so on screen.
- Month-end data understates intra-month risk.
- Costs are typical, not personal. FX spreads vary by institution and amount.
- The backtest charges conversion on rebalancing sales as well as purchases.
